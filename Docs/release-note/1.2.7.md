## 修复

### 笔记拖入分类

- 修复 Windows 桌面版中笔记拖入分类后未移动的问题。
- 笔记移动改用 Pointer Events，与侧栏固定项目和分类排序使用同一套可靠的指针会话，不再依赖会被原生文件投放通道拦截的 HTML5 拖放事件。
- 保留 Tauri 原生文件投放能力，从资源管理器拖入 Markdown 和图片的功能不受影响。
- 拖动笔记到分类标题、展开的分类内容区或未分类区域时均会显示目标状态；释放后会写入分类并刷新列表。
- 移动当前正在编辑的笔记前会先强制保存，避免分类迁移与自动保存并发导致内容丢失。
- 拖出窗口、失焦或页面隐藏时仍会可靠取消拖动，长侧栏边缘仍支持自动滚动。
