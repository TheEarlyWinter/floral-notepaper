# 花笺 v1.1.7

## 数据安全与搜索修复

- 修复中文全文搜索在摘要截取时可能触发 UTF-8 字节边界 panic 的问题。
- 将 `metadata.json` 与 Markdown 正文明确为权威数据；SQLite 与 FTS5 改为可自动重建的派生索引。
- 修复首次启用 SQLite 后旧笔记可能漏搜的问题，自动补建完整 FTS 索引。
- 修复从备份恢复、迁移数据目录后 SQLite/FTS 与真实笔记不同步的问题。
- 备份恢复、目录迁移和手动重建搜索索引后，都会从当前笔记数据重新生成搜索索引。
- 增强保存、删除和合并笔记的提交顺序，回收站失败时优先保护原始笔记。
- 启动时可恢复因异常中断而未登记到元数据的 Markdown 笔记。

## 编辑与导航修复

- 修复含特殊符号或重复标题时，大纲无法准确跳转到预览标题的问题。
- 修复快速输入标题时，大纲与延迟预览可能短暂不同步的问题。
- 大纲不再把代码块里的 `#` 误识别为标题。
- 修复外部文件的前进/后退导航，以及切换外部文件后标签、置顶状态残留的问题。
- 修复目录开关状态不同步，并改善大纲滚动后标题被顶部区域遮挡的情况。
- 格式化操作不再依赖废弃的 `execCommand("insertText")`。

## 稳定性与安全加固

- 外部文本和图片操作增加绝对路径、格式、大小、普通文件与图片内容校验。
- 单张图片最大限制为 50 MB，外部文本文件最大限制为 25 MB。
- 优化多关键词 FTS 搜索；例如“齿轮 强度”会按两个关键词共同匹配。
- 修复更新检查中环境变量覆盖值的微小内存泄漏。

## 验证

- 前端测试：29 个测试文件、115 项通过。
- Rust 单元测试：156 项通过。
- TypeScript 类型检查、前端构建、Rust release 构建、依赖审计均通过。
