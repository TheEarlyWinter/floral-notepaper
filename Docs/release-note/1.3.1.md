# 花笺 v1.3.1

## Windows x64 下载

本版本提供未签名的 Windows x64 包：

- 安装版：`floral-notepaper_1.3.1_x64-setup.exe`
- 绿色版：`floral-notepaper_1.3.1.exe`

## 问题修复

- **修复关闭临时便签导致后台高 CPU / GPU 占用死循环**：`recycle_notepad_window` 在便签预热窗口池已满时改用 `window.destroy()` 直接销毁多余窗口，避免 `window.close()` 再次触发 `CloseRequested` 并被前端 `onCloseRequested` 拦截后形成无限回收循环。
- **消除窗口尺寸保存路径的重复开库开销**：新增轻量 `config_store()` 仅读写 `config.json`，`save_surface_size` 改为先过滤零尺寸窗口再单次读取配置，不再在每次窗口关闭/回收时重复触发 `load_config()` 与 `floral.db` SQLite 初始化。
- **加固前端便签回收重入保护**：`NotePad` 组件的 `handleClose` 改为 `await recycleCurrentNotepad()`，确保回收或销毁完成前 `pendingCloseRef` 锁不会提前释放。
- **补充回归测试**：新增 `config_store_reads_and_writes_config_without_initializing_sqlite` 单元测试覆盖轻量配置读写路径。
