## 修复

### 侧栏排序拖动

- 修复固定侧栏项目和分类文件夹在 Windows 桌面版中无法拖动排序的问题。
- 排序改用 Pointer Events，不再与原生文件拖入能力争用 HTML5 拖放事件；从资源管理器拖入 Markdown 和图片、将笔记拖入分类的原有操作保持可用。
- 拖动离开窗口、窗口失焦或页面隐藏时会可靠清理拖动状态，避免后续点击或拖动被残留状态影响。
- 长侧栏拖动到滚动区域上下边缘时会自动滚动，分类排序目标限定为分类标题，避免笔记列表区域被误判。
- 排序仍会保存到本地配置，重启后保持。
