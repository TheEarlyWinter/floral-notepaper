本版本仅提供未签名的 Windows x64 包：

## 本次修复

- 修复应用内更新器默认仓库指向错误的问题，改为 `TheEarlyWinter/floral-notepaper`。
- 加强笔记分类、文件名、笔记 ID、附件和备份 metadata 的路径校验，拒绝不安全备份。
- 修复保存期间修改标签、置顶或正文时可能被旧保存结果覆盖的问题。
- 待办聚合、每日便笺和历史版本操作前会先保存当前编辑内容。
- 修复外部编辑 Markdown 后全文搜索索引长期陈旧的问题。
- 防止外部文件轮询覆盖尚未保存的编辑内容，并清理失效的导航历史。
- 转义 HTML/PDF 导出标题，避免特殊标题破坏导出文档。
- 固定 CI 使用 npm 11.6.2，避免 Node 24 Runner 的 lockfile 兼容问题。
