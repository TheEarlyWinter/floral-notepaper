# 花笺 v1.1.9

## Windows x64 下载

本版本仅提供未签名的 Windows x64 包：

- 安装版：`floral-notepaper_1.1.9_windows-x64-setup.exe`
- 绿色版：`floral-notepaper_1.1.9_windows-x64-portable.exe`

## 本次改进

- 新增“磁贴仅在桌面显示”选项。开启后，普通应用窗口会遮住磁贴，桌面整理时更安静。
- 分类标题旁新增新建按钮，可直接在指定分类创建笔记并自动展开分类。
- 优化磁贴尺寸：最小可缩至 140 × 96；回到编辑窗口时仍保留足够的编辑空间。
- 外部 Markdown 文件现可安全显示同目录下的相对图片；路径越界请求会被拒绝。
- 外部 TXT 导入补充 UTF-8 BOM、UTF-16 LE/BE BOM 与 GBK 编码识别，减少中文乱码。
- Markdown 格式化后会恢复编辑器原来的滚动位置，不再因为插入格式而跳回顶部。

## 已知边界

- 本版本继续沿用关闭后复用便签窗口的策略，以降低后台内存占用。
- 在 4GB 内存设备上连续创建大量仍保持打开状态的便签窗口，尚未完成真实设备压测，因此不宣称已彻底解决极端内存压力场景。
