## 本次改进

本轮为维护版：在真实环境实测关键路径后修复退出链路问题，并顺带优化工具栏体验。

### 退出链路修复（实测发现）

- 修复「关闭即退出」退不干净：设置中关闭“关闭到托盘”后 Alt+F4/关窗会保存并退出，不再因便签池隐藏窗口导致进程残留
- 修复托盘退出 / 主窗口关闭被休眠便签卡住：保存屏障只等待可见窗口，休眠便签不再让退出等 30 秒甚至永久
- 修复托盘退出与更新安装并发时误报「保存失败」：保存协调会话加互斥，连点退出或退出与安装撞车时后发请求被安全忽略
- 启动瞬间（界面未加载完）关闭窗口不再误退出，按配置隐藏到托盘

### 搜索定位

- 点击搜索结果时选中范围精确覆盖命中词（后端返回真实命中词长度），搜索框文字已变化时不再选中错位

### 体验优化

- 顶部工具栏按钮间距加大，窗口放大后不再挤在一起
- 工具栏可收纳：右上角新增折叠开关，收纳后显示「工具栏已收纳」，点击即可展开

### 细节修复

- 便签保存改为串行队列，自动保存与关闭保存不再可能乱序覆盖
- 大纲支持引用式链接标题的点击定位
- 关于面板许可证链接统一指向当前仓库
- 数据目录迁移期间有编辑且保存失败时，侧栏仍与后端目录同步
