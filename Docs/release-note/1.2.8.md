# 花笺 v1.2.8

## Windows x64 下载

本版本提供未签名的 Windows x64 包：

- 安装版：`floral-notepaper_1.2.8_x64-setup.exe`
- 绿色版：`floral-notepaper_1.2.8.exe`

## 修复

### 桌面钉桌

- 修复外部 Markdown 和内部笔记的钉桌窗口关闭后无法再次打开的问题。
- 关闭钉桌前统一完成未保存内容落盘，并强制销毁窗口，避免旧窗口对象残留。
- 同步前端钉桌状态与窗口销毁事件，降低快速关闭后立即重开的竞态。

### Markdown 图片预览

- 修复从资源管理器拖入图片后，编辑/分栏预览只显示 Markdown 图片语法、不显示图片的问题。
- 放行 Windows WebView2 实际使用的本地图片资源协议，并改进图片加载时机。

### PDF 导出

- PDF 正文现在包含笔记标题。
- 改用独立隐藏 WebView 直接写入 PDF，不替换主窗口 DOM，不改变当前主题，也不打开打印预览。
- 修复深色模式导出时的对比度问题，确保 PDF 使用白底深色文字。
- 修复 PDF 成功生成后主窗口仍显示红色错误提示的问题。
- 保留长文本和长 URL 的自动换行处理。

## 验证

- 前端 TypeScript、格式检查和相关 Vitest 测试通过。
- Rust `cargo check` 通过。
- Windows x64 release 构建通过。
- Windows 桌面实测通过：钉桌关闭后重开、拖入图片预览、深色/浅色 PDF 导出、标题显示、中文可读及主窗口无闪烁。
