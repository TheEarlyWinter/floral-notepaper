# 花笺 v1.2.0

## Windows x64 下载

本版本仅提供未签名的 Windows x64 包：

- 安装版：`floral-notepaper_1.2.0_windows-x64-setup.exe`
- 绿色版：`floral-notepaper_1.2.0_windows-x64-portable.exe`

## 本次改进

本轮以**稳定性与数据安全加固**为主，历经三轮完整代码审查（覆盖前端、Rust 服务端与更新器模块）并修复全部高危与中危问题：

### 数据安全

- 修复笔记 ID 冲突：同名文件（如 `abc.md` 与 `abc_xxx.md`）不再串号、误读、误删
- CLI 与 GUI 双进程写入改为跨进程文件锁串行，不再互相覆盖导致整批笔记丢失
- 笔记正文保存失败时自动回滚文件写入，不再出现「新正文配旧标题」的不一致
- 备份恢复改为「整体暂存 + 原子替换 + 失败回滚」，中途失败不会留下半恢复状态
- 附件迁移/添加失败自动回滚，不再产生孤儿附件文件
- reminders.json 损坏后自动自愈（保留损坏副本并重置）
- 提醒改为「通知送达后才标记」，窗口唤起或事件发送失败时下轮自动重试
- 每日便笺改用本地时区，凌晨 0~8 点不再打开「昨天」的便笺
- 备份恢复拒绝 zip 路径穿越、Windows 保留设备名与超大压缩包（zip 炸弹）
- SVG 图片拒绝内嵌 `<script>`，收紧 XSS 面

### 未保存内容保护

- Ctrl+W 关闭标签、关闭窗口、关闭便签小窗、恢复备份前都会先落盘未保存修改
- 保存失败后切换/新建/删除/合并笔记会被拦截，不再静默丢内容
- 保存失败状态会自动重试，不再「误报已保存」

### 更新器

- 下载改为逐跳校验重定向，不再绕过域名/协议白名单
- 更新包文件名拒绝路径穿越；SHA-256 大小写归一化
- MirrorChyan 下载与安装流程不再互相矛盾
- 清单通道（stable/beta）参与筛选，不会把 beta 更新当正式版展示
- 快捷键配置失败不再清空旧快捷键；录制结束后快捷键可正常恢复

### 体验与性能

- 大纲点击与滚动定位对含加粗/链接/行内代码的标题不再失效
- 数据目录迁移后图片不再全部失效
- 标签输入框按 Ctrl+S 可正常触发保存；删除笔记增加确认
- 面板数据加载防抖、保存队列限频、FTS 指纹检查移至搜索路径，大库更流畅
- 历史版本文件原子写入，单个损坏不再拖垮整个版本列表

## 已知边界

- 本版本继续沿用关闭后复用便签窗口的策略，以降低后台内存占用。
- 在 4GB 内存设备上连续创建大量仍保持打开状态的便签窗口，尚未完成真实设备压测，因此不宣称已彻底解决极端内存压力场景。
- 跨进程自动迁移（修改 `FLORAL_NOTEPAPER_DATA_DIR` 环境变量后 CLI 与 GUI 并发启动）暂未加迁移专用锁，属已知限制。
