# 花笺 v1.2.5

## Windows x64 下载

本版本提供未签名的 Windows x64 包：

- 安装版：`floral-notepaper_1.2.5_x64-setup.exe`
- 绿色版：`floral-notepaper_1.2.5.exe`

## 新功能

### 侧栏自定义排序

- 可上下拖动排序每日便笺、收件箱、日记流、笔记仪表盘、新建笔记、待办聚合和导入 Markdown。
- 可上下拖动排序分类文件夹。
- 排序会保存在本地配置中，重新启动后仍会保持。
- 旧配置、重复排序项与失效分类会自动归一化，不会影响现有笔记拖入分类的操作。
