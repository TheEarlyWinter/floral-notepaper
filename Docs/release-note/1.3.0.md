# 花笺 v1.3.0

## Windows x64 下载

本版本提供未签名的 Windows x64 包：

- 安装版：`floral-notepaper_1.3.0_x64-setup.exe`
- 绿色版：`floral-notepaper_1.3.0.exe`

## 新增与增强

### 编辑体验与生产力增强

- **笔记内查找与替换（`Ctrl+F` / `Ctrl+H`）**：支持区分大小写（`Aa`）、正则表达式（`.*`）与匹配计数，编辑区底层与预览区均实时高亮命中项，并在替换 / 全部替换时走原生编辑命令保留 `Ctrl+Z` 撤销栈。
- **侧边栏多选批量管理**：侧栏计数行提供显眼的「多选 / 完成」开关，选中多篇笔记后在底部操作栏一键批量移动分类、批量添加标签、导出 Markdown 或二次确认删除。
- **粘贴 / 拖入图片自动 WebP 压缩**：在「应用设置 → 图片压缩」中可配置开关与压缩质量（默认 `0.85`），自动跳过 GIF、SVG、WebP 与小于 `30 KB` 的小图，仅在体积更小时替换保存。
- **窄宽工具栏自适应**：顶部工具栏操作区改为不折行可横向滑动（带左右微调箭头与滚轮横滑），与右侧「编辑 / 分栏 / 预览」切换组隔离，展开侧边/反向链接面板或缩小窗口不再错位遮挡。

### 双向链接补全与本地相关笔记

- **`[[` 双向链接自动补全与点击跳转**：编辑正文输入 `[[` 时弹出本地笔记候选列表（支持 `↑↓`、`Enter` / `Tab`、`Esc` 与中文输入法组合输入保护），插入 `[[note:笔记ID|标题]]`；预览区支持直接点击、编辑区支持 `Ctrl+点击`（macOS 为 `Cmd+点击`）跳转对应笔记。
- **纯本地相关笔记推荐**：在「反向链接」面板下方基于本地 BM25 + 标签相似度计算推荐关联笔记，内置低分噪音阈值、中英文向量权重平衡、停用词清理与中文重叠词组自动拼接去重，支持一键插入链接与「已关联」状态标注。

### MCP / CLI 扩展与桌面磁贴 TTL

- **MCP Resources 只读资源暴露**：`--mcp` 新增 `resources/list`、`resources/templates/list` 与 `resources/read`，暴露 `floral://daily`、`floral://todos/pending`、`floral://notes` 及 `floral://note/{id}` 资源模板。
- **桌面磁贴定时自动关闭（TTL）**：`--cli pin-tile` 与 MCP `pin_tile` 支持 `--ttl <秒数>`（默认 `300s` 到期自动关闭）或 `--persist` 常驻，并在无前端界面运行时优雅降级排队。
- **设置页集成助手与外部活动日志**：新增「MCP 与 CLI 集成」区块，自动识别当前可执行文件路径、按主流客户端预设生成可一键复制的 `mcpServers` JSON 配置，并提供最近 CLI/MCP 外部活动记录查看与清空。

### 可选跨设备云同步（默认关闭）

- 新增默认关闭的 **WebDAV** 与 **Git** 双向同步（支持手动触发、连接测试与定时自动同步间隔）；密码 / Personal Access Token 仅存入系统安全凭据库（Windows Credential Manager / 系统钥匙串），不以明文写入 `config.json`，冲突时保留本地备份副本文档。

### 架构瘦身、渲染稳定性与多语言

- **包体与主模块瘦身**：移除随包捆绑的大型中文字体文件（优先回退本地 HarmonyOS Sans SC 与系统字体，保留标题用思源宋体），并将 `services/notes` 与 `MainWindow.tsx` 拆分为职责清晰的子模块，设置、图谱、仪表盘、查找栏等重型面板改为按需懒加载。
- **香港繁體中文（`zh-HK`）全量对齐**：补全全部设置与新增功能词条，修复 Windows 路径下的 pre-commit 格式化脚本与 CI Rust 构建缓存。
