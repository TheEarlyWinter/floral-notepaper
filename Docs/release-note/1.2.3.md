## 安全加固

本版本收紧了 Markdown 预览与外部文件的安全边界。

- 启用 Tauri WebView 内容安全策略，限制第三方脚本、样式、图片、字体和 frame 资源。
- 原始 HTML 渲染不再允许任意内联样式，降低不可信笔记覆盖界面的风险。
- 外部打开的 Markdown 与 HTML 文件始终按安全 Markdown 预览，不继承全局原始 HTML 渲染设置。
- 默认阻止远程 Markdown 图片，避免笔记预览无感请求第三方服务器。
- 外部 Markdown 的相对本地图片会经过路径和大小校验后复制到应用预览缓存，WebView 不再递归授权外部文件夹。

本地设置中选择的背景图仍正常使用。它会通过受限的 Tauri `asset:` 协议加载，不受本次 CSP 收紧影响。
