## 修复

### 贡献者头像恢复显示

v1.2.3 收紧 WebView 内容安全策略后，贡献者头像所用的 GitHub CDN 被图片来源策略拦截，导致“关于”面板头像无法显示。

本版本仅将 `https://avatars.githubusercontent.com` 加入图片白名单，恢复 GitHub 贡献者头像加载；没有重新开放任意远程图片。Markdown 中的远程图片仍默认阻止。
