## 本次改进

本轮为维护版：修复设置界面下半部分白屏问题（用户实测发现）。

### 修复：设置/关于面板下半部分白屏

- **现象**：在设置界面点击「记住小窗尺寸」「磁贴渲染 Markdown」等开关后，面板下半部分整块变白，白屏区域滚轮无反应
- **根因**：侧栏外层容器（`overflow-hidden`）内部多个绝对定位面板的溢出内容使其成为浏览器眼中的可滚动祖先，点击开关触发焦点滚动时被自动滚动数百像素，整个设置面板被推离视口，露出白色背景
- **修复**：
  - 外层侧栏容器改用 `overflow-clip`（不参与滚动祖先链），面板不再被自动滚动位移
  - 移除设置/关于面板的 `backdrop-blur`（消除合成层触发因素）
  - 滚动容器补齐 `min-h-0`（flex 布局标准修正）
- **验证**：实测连续点击多个开关后外层容器滚动位置恒为 0，面板完整覆盖视口；DOM 与渲染均正常
