- 绿色版：`floral-notepaper_1.2.9.exe`

## 新增

### Rust 原生 CLI 扩展与内置 MCP Server

- 保持原有 `--cli list|get|search|daily|create|export` 与 `{ ok, data, error }` JSON 契约向下兼容。
- `create` 支持 `--category`、`--tags`、`--pinned` 参数；新增 `append <note-id|daily>`、`update`（增量局部更新）、`delete`、`todos list|toggle`、`remind list|create|delete` 与 `pin-tile <note-id>`。
- 新增纯 Rust 内置 `--mcp`（stdio JSON-RPC 2.0，协议 `2024-11-05`），暴露 14 个工具（笔记读写搜索、每日便笺、待办读写、提醒管理与桌面钉磁贴），无需额外运行时，Windows 下严格保持 `stdout` 纯净无控制台干扰。
- 新增跨进程外部变更联动（`.external-rev` 与文件锁保护的 `external-commands.json` 队列）：外部 CLI/MCP 写入后 GUI 自动热刷新，若当前编辑器有未保存手敲内容则仅弹非破坏性提示不覆盖；支持通过 `pin-tile` 直接在桌面弹出对应磁贴。

### 命令面板与全局闪念快捕条

- 主窗口新增**命令面板**（默认 `Ctrl+K`，支持在「设置」中点击录制自定义快捷键或清空）：支持标题/分类/标签即时过滤、防抖 FTS5 全文搜索摘要、`>` 纯命令模式（13 项常用工作区操作）以及输入词直接快速新建笔记。
- 新增独立无边框悬浮**闪念快捕条**（默认全局快捷键 `Alt+Shift+Space`，支持在「设置」中自定义录制及托盘菜单呼出）：默认保存到收件箱，按 `Tab` 或点击切换为追加到今日便笺，`Enter` 提交并自动隐藏（带中文输入法 `isComposing` 保护），`Shift+Enter` 换行，`Esc`/失焦收起。
- 默认全局快捕快捷键在启动阶段采用非致命回退策略：即使与系统或已有快捷键冲突，也绝不影响原有快捷记录与显隐窗口快捷键。

### 上游交互特性同步

- **预览与桌面磁贴实时勾选任务列表**：在主窗口预览、分栏预览和桌面磁贴上可直接点击复选框精准回写原 Markdown 任务项，同时完整保留 `renderPolicy` / `rehype-sanitize` XSS 隔离与双链渲染。
- **分栏双向同步滚动升级**：同步上游异步块偏移测量、内容与字体尺寸重测及切换笔记取消旧任务机制，提升代码块、图片与长段落场景的同步精度。
- **磁贴双击编辑细节校准**：修复 SVG 控件区域双击误判与关闭回调依赖，保留 v1.2.5–v1.2.8 全部本地增强特性。
